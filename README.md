# RRAM Device Modelling Using COMSOL Multiphysics and MATLAB LiveLink

This repository contains the work completed during my **SN Bose Internship Program 2026** at the **National Institute of Technology Silchar**.

## About the Internship

The internship focused on the numerical modelling of **Resistive Random-Access Memory (RRAM)** devices using **COMSOL Multiphysics 6.0** and **MATLAB LiveLink**.

The work involved developing and debugging a multiphysics simulation framework for filamentary RRAM and automating the simulation workflow through MATLAB.

## Work Performed

- Developed a 2D axisymmetric RRAM device model in COMSOL Multiphysics.
- Studied the filamentary switching mechanism involving SET and RESET processes.
- Implemented coupled Heat Transfer, Electric Currents, Electrical Circuit, and electromagnetic heating physics.
- Studied a thermodynamic/free-energy framework for modelling filament evolution.
- Integrated COMSOL with MATLAB using LiveLink for MATLAB.
- Automated the OFF → SET → ON → RESET simulation workflow.
- Performed systematic debugging of MATLAB and COMSOL models.
- Extracted simulation data and performed I–V post-processing.
- Investigated numerical issues affecting RESET convergence and device-voltage scaling.

## Software & Tools

- COMSOL Multiphysics 6.0
- MATLAB
- MATLAB LiveLink for COMSOL

## Current Status

The internship established a functional **COMSOL–MATLAB simulation and post-processing framework**. The models could be executed through the automated workflow and generate stage-wise simulation data.

The results should be considered **preliminary numerical outputs rather than fully validated RRAM switching characteristics**. In particular, the RESET free-energy minimization and device-voltage scaling require further investigation.
